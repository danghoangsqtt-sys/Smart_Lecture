# P47 Specification — Default Circuit Teacher Guide

## Goal

Make the instructional intent of the six default circuit-simulation challenges visible to teachers before they launch a game.

## Implementation

- Show a collapsible guide whenever the teacher uses the default challenge pack rather than custom challenges.
- List the observation focus for LED, AND, NOT, D Flip-Flop, Half Adder and Full Adder.
- Include the wire-direction reminder and the role of Probe/Oscilloscope.

## Quality Gate

- Typecheck and production build pass.
- Browser E2E regression passes.
- React Doctor changed-scope scan has no issues.
