# P20 Specification — Presentation Pointer Toolbar

## Goal

Make the three essential PowerPoint teaching tools immediately discoverable during a slide show: laser pointer, freehand pen and highlighter.

## Interaction

- A floating bottom toolbar mirrors the placement of slideshow pointer controls.
- Laser is transient and never saved as ink.
- Pen and highlighter create session-persistent annotations.
- Circle, underline, line, undo and clear-current-page remain available as compact secondary controls.

## Accessibility

Every control has a Vietnamese accessible name and a tooltip describing its effect.
