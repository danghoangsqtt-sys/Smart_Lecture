# P24 Specification — Presenter Shortcuts

## Goal

Let teachers switch presentation tools without leaving the slide surface.

## Shortcuts

- `L`: Laser pointer
- `P`: Pen
- `H`: Highlighter
- `E`: Per-stroke eraser
- Arrow/PageUp/PageDown: Slide navigation

Shortcuts are ignored while typing in inputs, textareas, selects or editable content, and when a browser modifier key is held.
