# P36 Specification — Advanced Presenter Shortcuts

## Goal

Make all requested emphasis tools available from the keyboard during a projected lesson.

## Shortcuts

- `C`: circle/ellipse
- `U`: underline
- `D`: straight line

Existing `L`, `P`, `H`, `E` and page-navigation shortcuts remain unchanged. All tool shortcuts are ignored while typing or using modifier keys.

## Quality Gate

Browser E2E verifies keyboard selection for pen, circle, underline and line controls.
