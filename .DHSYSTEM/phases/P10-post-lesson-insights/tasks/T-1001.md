# T-1001 — Post-lesson Insights v1

## Objective

Expose an actionable teaching summary for the selected class and subject without introducing a second analytics data store.

## Paths

- `server/src/routes/teachingLogs.routes.ts`
- `web/src/pages/TeachingHubPage.tsx`
- `scripts/e2e-regressions.mjs`
- `.DHSYSTEM/phases/P10-post-lesson-insights/PHASE-STATE.md`

## File-Level Plan

- Add a class-scoped, teacher-only summary endpoint derived from `teaching_logs`, attendance references and curriculum items.
- Render the selected class/subject summary and recent sessions in Teaching Hub.
- Add regression assertions for authorization, aggregation and subject filtering.

## Acceptance Criteria

- Summary is denied to students and teachers outside the class.
- Metrics distinguish active/completed sessions and course progress.
- Recent sessions remain useful without exposing student-private data.
